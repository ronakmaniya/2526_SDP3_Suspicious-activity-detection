Project Title

Real-Time AI-Based Suspicious Activity Detection and Human Monitoring System Using CCTV Surveillance

1️⃣ Introduction
1.1 Purpose

The purpose of this system is to design and implement a real-time intelligent CCTV surveillance system that:

Detects human presence

Classifies activity as Normal or Suspicious

Displays bounding boxes in real time

Stores processed CCTV footage with timestamps and annotations

Logs suspicious events for review

2️⃣ System Overview

The system performs:

📡 Real-time CCTV monitoring at 24 FPS

👤 Human detection using YOLO

🧠 Activity classification using Video Swin Transformer

🟢 Green box for normal activity

🔴 Red box for suspicious activity

🕒 Timestamp overlay on video

💾 Storage of processed video (MP4 format)

📊 Logging of detection events

5️⃣ Functional Requirements
FR1 – Real-Time CCTV Monitoring

System shall process video at 24 FPS.

Frames shall be buffered in sliding window of 16 frames.

Processing delay ≤ 1.5 seconds.

FR2 – Human Detection

System shall detect humans in video frames using YOLOv8x.

Bounding box coordinates shall be generated.

Only detected human regions shall be analyzed for activity.

FR3 – Activity Classification

System shall classify detected human activity as:

Normal

Suspicious

FR4 – Visual Display Logic

If classification result is:

Normal → 🟢 Green bounding box

Suspicious → 🔴 Red bounding box

Bounding box shall include:

Confidence score

Label

Timestamp

Example display:

[SUSPICIOUS | 0.94 | 14:32:10]

FR5 – Timestamp Overlay

System shall overlay current timestamp on each frame.

Timestamp format: HH:MM:SS

Timestamp shall be visible in both live display and stored video.

FR6 – Video Storage

Processed CCTV video shall be stored in MP4 format.

Stored video shall include:

Bounding boxes

Labels

Confidence score

Timestamp overlay

Stored video shall be accessible for later review.

FR7 – Alert Logging

System shall store in database:

Timestamp

Activity label

Confidence score

Video file path

Duration of suspicious activity

FR8 – Video Upload Mode

User can upload MP4 file.

System processes file and returns annotated video.

Annotated version shall be stored.

8️⃣ Real-Time Processing Workflow

Capture frame at 24 FPS.

Apply YOLOv8x to detect humans.

Collect 16-frame sliding window.

Pass frames to Video Swin.

Get classification result.

Draw bounding box:

Green if normal

Red if suspicious

Overlay timestamp.

Display frame on frontend.

Save annotated frame to output MP4.

If suspicious:

Log event in database.
